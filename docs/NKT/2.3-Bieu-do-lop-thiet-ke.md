## Biểu đồ lớp thiết kế (tham khảo style bài mẫu `chuong2.md`)

Trong bài mẫu, “Sơ đồ lớp thiết kế” được vẽ theo dạng **UML trong phạm vi từng service**, gồm:

- **Controllers**: nhóm các API/endpoints của service.
- **Domain Models**: các lớp `models.py` (Django Models).
- Quan hệ chính: `<<use>>` (controller dùng model), `composition` (1 chứa nhiều), `inheritance` (kế thừa).

Phần dưới đây được làm lại để **khớp tên lớp/tên hàm đúng với code hiện có** trong dự án (không dùng các lớp tự bịa như ViewSet/Serializer).

## 2.3 Product Service

### 2.3.1 Sơ đồ lớp thiết kế

```mermaid
classDiagram
direction LR

namespace product_service {
    class ProductController {
        +product_list()
        +product_detail(pk)
        +category_list()
    }
    class AdminProductController {
        +manage_product()
        +delete_product_manage(pk)
        +update_stock()
        +list_attributes()
        +create_attribute()
        +delete_attribute(attribute_id)
        +create_attribute_value(attribute_id)
    }

    class Category {
        +int id
        +string name
        +string slug
        +text description
        +string icon

    class Product {
        +int id
        +int category_id
        +string name
        +text description
        +decimal price
        +string image_url
        +int supplier_id
        +string product_type
        +json attributes

    class Book

        +int id

        +string name
        +decimal price_override
        +int stock

        +string image_url
        +json options
    }

    class Attribute {
        +int id
        +string name
        +string slug
    }
    class AttributeValue {
        +int id
```

Sơ đồ lớp bao gồm:

- `Product`, `Category`: lõi dữ liệu sản phẩm và danh mục.
- `ProductVariant`, `Attribute`, `AttributeValue`, `ProductVariantOption`: mô hình biến thể và ánh xạ thuộc tính.
- `ProductController`, `AdminProductController`: các API được triển khai trong `product_app/views.py`.

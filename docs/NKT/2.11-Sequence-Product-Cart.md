# 2.11 Sequence diagrams — Product view & Add-to-cart flows

Tập hợp 5 luồng phổ biến liên quan tới "Xem sản phẩm" và "Thêm vào giỏ hàng". Mỗi sơ đồ là PlantUML sequence diagram, được viết dựa trên code thực tế:

- Frontend JS (templates /*product_detail.html, homepage.html, search.html, cart.html*/)
- API Gateway (RoutingMiddleware forwarding /api/cart/ -> cart-service)
- Cart Service (views.add_to_cart in services/cart_service/cart_app/views.py)
- Tracking Service (/api/tracking/*)
- Chatbot Service (/api/chatbot/ask)

Lưu ý: diagram dùng các endpoint và hành vi chính xác từ code: `POST /api/cart/add/`, `GET /api/cart/`, tracking POSTs (`/api/tracking/log-cart/`, `/api/tracking/log-view/`) và chatbot `POST /api/chatbot/ask`.

## 2.11.1 Product detail -> Add to cart (full flow)

```plantuml
@startuml
actor User
participant "Browser (product_detail.js)" as Browser
participant "API Gateway\nRoutingMiddleware" as Gateway
participant "Cart Service\nadd_to_cart" as CartSvc
participant "DB (Cart, CartItem)" as DB
participant "Tracking Service" as Track
participant "Chatbot Service" as Chatbot

User -> Browser: click Add to Cart (qty N)
Browser -> Gateway: POST /api/cart/add/\nheaders: Authorization: Bearer <token>\nbody: {product_type, product_id, quantity, price, product_name, image_url}
activate Gateway
Gateway -> CartSvc: forward POST /api/cart/add/ (same headers/body)
activate CartSvc
CartSvc -> DB: Cart.objects.get_or_create(customer_id)
activate DB
DB --> CartSvc: cart (created?|existing)
deactivate DB
CartSvc -> DB: CartItem.objects.get_or_create(cart, product_type, product_id, variant_id)
activate DB
DB --> CartSvc: cart_item (created?|existing)
CartSvc -> DB: cart_item.save() [if exists: update quantity]
DB --> CartSvc: ok
deactivate DB
CartSvc --> Gateway: 200/201 JSON { success: true, data: cart.to_dict(), message }
deactivate CartSvc
Gateway --> Browser: 200/201 JSON
deactivate Gateway

Browser -> Track: POST /api/tracking/log-cart/\nbody: {product_id, product_type, action_type:'add', price, quantity}
activate Track
Track --> Browser: 200 OK (async fire-and-forget in code)
deactivate Track

Browser -> Chatbot: POST /api/chatbot/ask\nbody: {user_id, trigger:'cart', product_id}
activate Chatbot
Chatbot --> Browser: 200 JSON { success:true, reply, recommendations }
deactivate Chatbot

Browser -> Gateway: GET /api/cart/ (refresh badge)
activate Gateway
Gateway -> CartSvc: forward GET /api/cart/
activate CartSvc
CartSvc -> DB: Cart.objects.get(customer_id) + to_dict()
DB --> CartSvc: cart data
deactivate DB
CartSvc --> Gateway: 200 JSON { success:true, data: cart }
deactivate CartSvc
Gateway --> Browser: 200 JSON
deactivate Gateway

Browser --> User: show success message, update cart badge

@enduml
```

## 2.11.2 Quick add from Homepage (one-click add)

```plantuml
@startuml
actor User
participant "Browser (homepage.js)" as Browser
participant "API Gateway\nRoutingMiddleware" as Gateway
participant "Cart Service\nadd_to_cart" as CartSvc
participant "Tracking Service" as Track

User -> Browser: click card 'Add' (no product page)
Browser -> Gateway: POST /api/cart/add/\nheaders: Authorization\nbody: {product_type, product_id, quantity:1, price, product_name, image_url}
activate Gateway
Gateway -> CartSvc: forward POST /api/cart/add/
activate CartSvc
CartSvc -> DB: get_or_create Cart & CartItem ... (same as 2.11.1)
CartSvc --> Gateway: 200/201 JSON
deactivate CartSvc
Gateway --> Browser: 200 JSON
deactivate Gateway

Browser -> Track: POST /api/tracking/log-cart/ (log action)
Browser -> Browser: loadRecommendations()  // homepage calls loadRecommendations after add

Browser --> User: show 'Added to cart' toast; refresh badge

@enduml
```

```plantuml
DB --> CartSvc: ok
deactivate DB
CartSvc --> Gateway: 200 JSON
deactivate CartSvc

deactivate Gateway

@enduml
```
